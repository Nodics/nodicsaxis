# Nodics Axis Claude Guidance

Read and follow `AGENTS.md` before making changes in this repository.

Axis is a separate Back Office browser application. Keep backend authority,
business rules, persistence, authentication enforcement, authorization,
workflow execution, secrets, tenant governance, and runtime contracts in
backend-owned Nodics modules.

Do not import sibling Nodics source, create frontend authority paths, or move
backend behavior into Axis.
